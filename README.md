# 竞争结合分析小工具

Windows 桌面竞争结合拟合工具 · 免费交流版 1.0

输入浓度和荧光数据，拟合竞争结合常数 Kc；也可以用假设的 Kc 探索模型对应的浓度序列。

## 下载

到 [Releases](https://github.com/claritycheng/competitive-binding-tool/releases/latest) 下载 `Competitive-Binding-Tool-v1.0-Windows.zip`，解压运行 EXE。不用装 Python，**不需要激活，下载就能用**。

适用于 Windows 64 位。已在当前 Windows 电脑验证启动与基本功能，其他电脑的兼容性欢迎反馈。

## 两个功能

- **实测数据拟合**：输入实际配制的竞争物总浓度 x 和对应荧光 y，固定 Kg、G0、H0，联合拟合 Kc、Ig、Io，显示标准误、R²和残差均方。
- **模型模拟**：输入递增的 y、假设的 Kc 范围与末点浓度，反推模型对应的浓度序列，可导出带模拟标记的 CSV。它用于教学、模型检查和方案探索；反推浓度不等于实验实测浓度，回代拟合也不是独立实验验证。

启动默认进入实测 x/y 的拟合页。详细操作见 [使用说明](使用说明.md)。

## 输入单位

| 参数 | 含义 | 界面单位 |
| --- | --- | --- |
| Kg | 主体与探针的结合常数 | M⁻¹ |
| G0 | 探针总浓度 | M |
| H0 | 主体总浓度 | M |
| x | 竞争物总浓度 | μM |
| Kc | 主体与竞争物的结合常数 | M⁻¹ |
| y | 荧光信号 | 同一数据集保持相同单位 |

x 和 y 一一对应，支持逗号、空格、制表符或换行分隔。至少需要 4 个不同的浓度点，实际分析应覆盖足够的滴定范围。**1 μM = 1e-6 M**，注意固定参数与横坐标的单位不同。

## 模型与结果

模型为 H + G ⇌ HG、H + C ⇌ HC，两种配体竞争同一个主体位点，分别按 1:1 结合；不包含 HGC 三元复合物、协同作用、多位点或高阶结合。

沿用原工具的质量守恒方程和荧光模型，采用非线性最小二乘拟合。Ig 为模型中的游离探针荧光水平，Io 为无竞争物时的荧光水平。默认固定参数和模拟页数值只是演示，不代表某种材料的实测结论。

结果中的 ± 是由拟合协方差估计的标准误，不是重复实验的标准差。残差均方为 SSR/(n−3)，未按观测误差归一化，不能当作已知测量误差下的约化卡方。R²高不保证参数可靠或模型适用。

该版本采用原有牛顿迭代求解与单初值拟合，不保证所有参数范围都收敛或得到全局最优解。请确认体系达到平衡、模型适用，并核对初值敏感性、滴定范围和参数不确定性。程序不会自动修正稀释、背景或内滤效应。
